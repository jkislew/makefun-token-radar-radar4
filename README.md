Launch Radar, fourth generation: a token launch radar over the full sealed DefiLlama universe. All 758 snapshot protocols are accounted for exactly once — 630 pre-token protocols ranked by implied launch value and 128 live protocols carried at the market's own cap, with the house watchlist covered 40/40. Pricing is an ensemble fitted only on the snapshot's 128 tokenized peers: a per-category comp stack (median market-cap/TVL multiples blended in log space, tilted by a fitted size law) geometrically blended 0.6/0.4 with a ridge regression on log market cap. The program grades itself out of sample on every run — leave-one-out, both split halves, and three seeded five-fold passes, with the two earlier model generations scored on the identical schemes — and prints the grades on the dashboard: ensemble median log-MAE 1.5804 against the previous generation's 1.6505. Every row carries an honest value interval and a deposit-sized farm plan ($100 / $250 / $500 / $1,000 by TVL tier) written from its category playbook, regenerated by the dashboard itself so page and board never disagree.
